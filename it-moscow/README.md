# IT.МОСКВА

Учебный сайт колледжа информационных технологий. Сценарий для абитуриента: выбрать специальность, разобраться с поступлением и перейти к официальным инструкциям.

## Запуск

Откройте `front/index.html` в браузере. Для просмотра набора компонентов откройте `front/UI-kit.html`. Установка зависимостей не требуется.

```text
it-moscow/
├── docs/
│   └── tech_treb.pdf
├── analysis/
│   ├── audience.md
│   └── cjm.md
├── design/
│   ├── desktop.svg
│   ├── mobile.svg
│   ├── ui-kit.svg
│   └── research.svg
└── front/
    ├── index.html
    ├── UI-kit.html
    ├── styles/main.css
    └── scripts/main.js
```

В `analysis/` находятся гипотезы о целевой аудитории и её пути. В `design/` лежат векторные макеты, которые можно импортировать в Figma. Раздел поступления ведёт на официальные ресурсы.
