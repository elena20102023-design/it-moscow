# Целевая аудитория «Стола заказов»

Основная аудитория — студенты IT.МОСКВА, которые ищут учебники, конспекты или материалы для проектов. Вторичная — студенты, готовые передать учебник, поделиться своим конспектом или открытым ресурсом.

**Персона.** Маша, 17 лет, второй курс. Готовится к зачёту по компьютерным сетям. Смотрит доску с телефона между парами. Хочет быстро найти материал по предмету или оставить запрос.

**Проверка гипотезы.** Попросить студентов найти книгу по SQL, отфильтровать запросы и опубликовать объявление. Отметить, где они останавливаются и чего им не хватает для обмена.
