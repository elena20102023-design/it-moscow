# ПочтоКит

Учебный сервис для маркетологов малого бизнеса, которые сами готовят email-рассылки и отчитываются о результатах. Основной сценарий показывает, как Алина запускает первую кампанию.

## Запуск

Откройте [index.html](index.html) в браузере. Установка и сервер не нужны.

1. Вставьте тестовые контакты и нажмите «Проверить и сохранить».
2. Перейдите к кампании и выберите шаблон письма.
3. Проверьте письмо и список получателей в предпросмотре.
4. Нажмите «Смоделировать отправку» и посмотрите отчёт.

Браузер сохраняет контакты, черновик и историю кампаний в локальном хранилище, если оно доступно. Отправка и показатели отчёта демонстрационные.
